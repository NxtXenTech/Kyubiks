How to connect:
1. Connect Main Power → Multi Plug.
2. Rotate CPU to see back ports.
3. Rotate Monitor to see back ports.
4. Connect CPU + Monitor → Multi Plug.
5. Connect CPU → Monitor video cable.
6. Connect Keyboard → CPU.
7. Connect Mouse → CPU.
8. Press the CPU power button to start.
9. Type password **1234** using Keyboard and press Enter.
10. Hold a connected port for 0.7 sec to disconnect.
